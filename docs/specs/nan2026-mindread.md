## 1. 개요

**한 줄:** 내 선택 패턴을 읽는 AI 경비를 상대로, 두 금고 중 덫이 없는 쪽을 골라 판돈을 불리고 — 털리기 전에 챙겨 나오는 심리전 게임.

**심사 서사 (이 게임의 존재 이유):**
1. **게임 안** — AI가 나를 읽는다(통계 예측기 + LLM 심리전), 나는 AI가 입 밖에 낸 읽기를 역이용한다. LLM 없이는 심리전이, 예측기 없이는 게임이 성립하지 않는다.
2. **게임 밖** — 전작을 "실패 축이 없다"는 구조 진단으로 중단하고, 같은 아키텍처(어휘는 LLM·집행은 결정론)를 다른 장르에 이식해 1.5일 만에 재구축했다. 중단 판단의 포스트모템과 재사용 과정이 repo에 커밋으로 남아 있다 — "AI의 다음 단계를 설계할 디렉터"의 실물 증거.
3. **방법론** — 코드를 짜기 전에 "예측기가 사람을 잡는가"를 시뮬레이션으로 실측해 게임의 재미 전제를 검증했다(§3.3). 이 과정 자체가 AI 활용 기술 문서의 한 장이 된다.

**플랫폼:** 웹 (데스크톱 우선, 클릭·터치만으로 플레이 가능). GitHub Pages, 링크 클릭 즉시 플레이. 로그인·설치 없음.

**전작이 남긴 제1 계약** (`C-player-needs-a-failure-axis`): 난이도는 "플레이어가 못 하는 것"에서 나온다. 이 게임의 실패 축은 ① **인간은 랜덤을 만들지 못한다**(시뮬 실측: 사람 흉내 정책은 50% 기준선 대비 67~82% 잡힘) ② **욕심**(스트릭을 쌓을수록 몰수 리스크가 커진다). 둘 다 밸런스 값이 아니라 인지 한계와 수학이라, 전작의 사인("값 조정으로 도달 불가능한 쉬움")이 재발할 수 없다.

## 3. 게임 디자인

### 3.1 코어 루프 (1판 ≈ 3~4분, 12라운드)

```
[관찰 2라운드]  덫 없음. AI는 지켜만 본다 — "지금부터 당신을 관찰한다"
   선택·수익·스트릭은 본게임과 동일하게 동작(안전한 온보딩) — 첫 덫 라운드에
   이미 미정산이 쌓여 있어 몰수 긴장이 곧바로 성립한다
      ↓
[본게임 10라운드]  매 라운드:
   ① AI가 몰래 한쪽 금고에 덫 (로컬 앙상블 즉답 — 대기 0초)
   ② 플레이어: 왼쪽/오른쪽 금고 클릭 (또는 ←/→)
   ③ 즉시 판정 — 통과: 미정산 수익 += 기본금 × 스트릭, 스트릭+1
                 잡힘: "예측됨" 스탬프 + AI가 근거 표시("3연속 왼쪽 뒤엔 늘 오른쪽이었지")
                       미정산 전액 몰수, 스트릭 0
   ④ [정산] 버튼: 라운드 사이 언제든. 미정산 → 은행 확정, 스트릭 0
      ↓
[읽기 세션 3회]  관찰 직후 · 본게임 4R 후 · 7R 후 — LLM이 이력을 읽고
   심리 프로파일 한 줄 + 도발 + 전략 카드 교체 (타이핑 연출, 전작 인터벌 재사용)
      ↓
[종료]  10라운드 소진(미정산은 자동 정산) → 은행 ≥ 목표액이면 승리("금고 털이 성공"), 미달이면 패배
   양 경로 모두 LLM 심리 분석 리포트(≈400자) + 칭호 → 리스타트 1클릭
```

- 판정·정산이 **라운드 안에서 즉시** 일어난다 — 전작 amendment #5의 교훈(정산은 비트 안에, 시차 0) 그대로.
- 조작은 클릭 2종 + 정산 버튼뿐. 심사자 입력 부담 0.

### 3.2 판돈 수학 — 욕심의 축

초안 상수 (아래 시뮬 게이트 2차로 확정, `budget` 유닛 테스트 대상):

| 항목 | 초안값 | 의도 |
|---|---|---|
| 기본금 | 100 | 라운드 통과 수익 = 100 × 현재 스트릭 (1→2→3…) |
| 몰수 | 미정산 전액 | 스트릭이 길수록 판이 커진다 — 욕심의 가격 |
| 정산 | 무료 행동, 스트릭 리셋 | "챙길까 더 갈까"가 매 라운드의 결정 |
| 목표액 | 1,200 (조정 예정) | 아래 성립 조건을 만족하는 값으로 시뮬 확정 |

**성립 조건 (시뮬 게이트 2차의 판정 기준 — 사전 선언):**
1. AI에게 읽히는 플레이(통과율 ~30%)는 목표액에 도달 못 한다 (승률 <10%)
2. 역읽기에 성공한 플레이(통과율 45~55%)는 정산 타이밍이 좋으면 도달한다 (승률 40~70%)
3. 무전략 랜덤(통과율 50%) + 무전략 정산은 그 사이 (승률 15~35%) — 운으로도 가끔 이겨야 리스타트 동기가 생긴다

### 3.3 예측 엔진 — 로컬 앙상블 (시뮬 게이트 1차 통과)

**구성:** 예측기 5종의 성적 가중(지수감쇠) 앙상블. 전부 결정론·로컬·즉답.

| 예측기 | 잡는 패턴 | 프라이어(핵심) |
|---|---|---|
| freq | 위치 편향 | 약한 중앙/균등 |
| ngram1 | 직전 선택 → 다음 | **반복 회피**(사람의 대표 편향) |
| ngram2·3 | 짧은 시퀀스 습관 | 없음 (데이터로만) |
| wsls | 잡힘/통과 직후 반응 | **잡힌 문 회피**(lose-shift, 보편 편향) |

**시뮬 실측 (2026-08-08, `scripts/mindread_sim.js` — 관찰 2 + 본게임 10, 2000게임×정책):**

| 상대 정책 (ε=0.25 노이즈) | 2문 적중률 (기준선 50%) |
|---|---|
| 반복 회피형 | **82.4%** |
| 순환형 | 69.7% |
| 승유지·패전환형 | 66.7% |
| 혼합형(사람에 가장 근접) | **74.3%** |
| 2차 추론형(잡힌 문 일부러 반복) | 51.0% — 유일하게 중립화 |
| 순수 랜덤 | 50.0% (과적합 없음 확인) |

**판정:** 사전 선언 기준(패턴 평균 62%+·혼합형 55%+·랜덤 47~53%) 전부 통과 — 패턴 평균 68.8%. 3문은 ~40%로 탈락 → **2문 확정**. (표본 2000게임·시드 없음 — 재실행 시 ±1pt 변동)
1차(프라이어 없는 백지 앙상블)는 미달이었고, 인간 편향 프라이어 + 관찰 라운드 도입으로 통과 — 경위는 기술 문서에 기재한다.

**설계 함의:** 2차 추론(AI가 입 밖에 낸 읽기를 역이용)만이 앙상블을 중립화한다 = "내가 AI를 읽었다"가 이 게임의 실제 승리 스킬이라는 것이 실측으로 보장된다. 이것이 LLM 층이 필요한 이유이기도 하다 — 역이용을 시작한 플레이어를 상대하는 것은 통계가 아니라 메타 판단(§3.4 `CONTRARIAN`).

### 3.4 디렉터(LLM) — 권한 경계

**원칙 (전작 승계): LLM에게는 어휘를, 집행은 결정론으로.** LLM은 수치·좌표·확률을 정하지 못한다.

**입력 (읽기 세션마다):** 선택 이력 전체, 잡힘/통과 이력, 정산 타이밍·스트릭 행동(욕심 지표), 앙상블 예측기별 성적(어떤 패턴이 잡히는 중인지 — LLM은 이 통계를 언어화하고 메타 판단만 한다).

**출력 — 디렉티브 v2:**
```json
{
  "read":     "≤60자 — 이력의 실제 패턴을 반드시 1개 지목 (화면 표시)",
  "taunt":    "≤40자 — 다음 라운드 전 도발",
  "strategy": "BALANCED|PRIOR_HEAVY|RECENT_ONLY|PATTERN_HEAVY|CONTRARIAN|BAIT",
  "baitDoor": "L|R|NONE — BAIT일 때만: taunt가 그 문을 직접 언급한다",
  "intent":   "≤80자 — 설계 의도 (리포트·기술 문서용)"
}
```

- `strategy` = 앙상블 가중 **프리셋 선택**(프리셋 수치는 엔진 소유). `CONTRARIAN`: 앙상블 예측의 반대편에 덫 — 역이용을 시작한 플레이어 대응. `BAIT`: 도발-덫 연동 — 말로 문을 지목하고, 지목당한 사람의 회피/반발 편향을 엔진이 가중.
- 검증(zod, 전작 validator 재사용): enum·길이·`baitDoor`는 `BAIT`일 때만 허용. 위반 시 폴백.
- **호출 예산: 런당 5회** (읽기 세션 3 + 최종 리포트 1 + 타이틀 워밍업 1 — 워밍업은 전작 amendment 그대로). 세션 상한 20회·일일 캡·CORS 등 프록시 설정 전부 재사용.
- **폴백 (전작 패턴):** 4초 타임아웃·검증 실패 시 `BALANCED` + read/taunt 뱅크(세션별 3종 × 3). 게임은 로컬 앙상블만으로 100% 성립 — 폴백은 목소리만 대체한다.

**최종 리포트:** 전체 런 요약 → 심리 프로파일 400자 + 칭호(예: "청개구리", "간 큰 도둑"). 실패 시 정적 템플릿.

### 3.5 비주얼·오디오

- 전작 아이덴티티 유지: 다크(#0a0a0f) + 무채색 지오메트리 + **레드 = AI의 것**(대사·덫 판정·시선). 외부 에셋 0.
- 화면: 상단 AI의 눈(플레이어 커서를 따라간다 — "관찰당하는" 체감) + 대사줄, 중앙 금고 2개, 하단 은행/미정산/스트릭/라운드/[정산].
- 주스(전작 재사용): 잡힘 = 화면 흔들림 + 레드 플래시 + "예측됨" 스탬프, 통과 = 코인 파티클 + 카운트업, 정산 = 금고 소리. zzfx 4종.
- '디렉터 로그' 토글(전작 재사용): 디렉티브 JSON 원본 — 시연·기술 문서 스크린샷용.

4. 판돈 수학: §3.2 성립 조건 3항을 시뮬로 확인 후 상수 확정 (유닛 + 문서).
5. 정상 경로: 읽기 세션에서 `read`가 실제 이력의 패턴을 지목 (수동 2런).
6. 장애 경로: 프록시 차단·타임아웃·스키마 위반 각각에서 폴백으로 무정지 진행 (유닛 + 수동 1회).
7. 잡힘 판정 시 근거(무엇을 읽었는지) 표시 — "AI가 나를 읽고 있다" 30초 체감의 담보.
8. 세션 호출 상한·일일 캡 동작.
9. 산출물: 30~60초 영상, 게임 소개 PDF, AI 활용 기술 문서 PDF(게임 내 AI 2층 + 개발 방법론 + 전작 중단 판단) 완료.
10. 신청 폼 제출 — **승제 직접**, 8/10 오전.

## 7. 리스크·전제

- **체감 난이도 (최대 리스크):** 적중률 67~82%는 "소름"과 "좌절" 사이에 있다. 실플레이에서 좌절로 판정되면 값이 아니라 **규칙 레버**로 대응한다(사전 준비): ⓐ 앙상블 확신도가 임계 미만이면 그 라운드 덫 없음(자동 숨 고르기) ⓑ 3연속 잡힘 시 관찰 라운드 1회 삽입("경비 교대"). — 전작 교훈: 같은 계열 레버를 반복해서 당기지 않는다.
- **LLM read 품질:** 12라운드 이력은 짧다 → 앙상블 통계(무엇이 잡히는 중인지)를 프롬프트에 제공, LLM은 통계의 언어화 + 메타 판단만. 날조 방지: `read`가 지목한 패턴이 이력에 실존하는지는 심사 불가하므로, 프롬프트에 "통계에 있는 패턴만 말하라" + 리포트 검증은 수동 2런.
- **유료 API:** 런당 5회 × haiku — 전작보다 저렴. 캡 재사용.
- **재직자 보증·약관:** 전작과 동일 — 승제 액션 아이템(제출 전).
- **일정:** 신규 코드는 앙상블 이식(완성된 시뮬 코드 기반)·2문 씬·판돈뿐이라는 것이 이틀 성립의 전제. P1이 8/9 오전을 넘기면 컷라인 즉시 가동.
