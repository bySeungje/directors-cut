## 1. 개요

**한 줄:** 내 선택 패턴을 읽는 AI 경비를 상대로, 두 금고 중 덫이 없는 쪽을 골라 판돈을 불리고 — 털리기 전에 챙겨 나오는 심리전 게임.

**심사 서사 (이 게임의 존재 이유):**
1. **게임 안** — AI가 나를 읽는다(통계 예측기 + LLM 심리전), 나는 AI가 입 밖에 낸 읽기를 역이용한다. **AI의 말은 허세가 아니라 계약이다**(§3.4 약속 창) — 심리전이 기계적으로 정직하다.
2. **게임 밖** — 전작을 "실패 축이 없다"는 구조 진단으로 중단하고, 같은 아키텍처(어휘는 LLM·집행은 결정론)를 다른 장르에 이식해 1.5일 만에 재구축했다. 과정 전체가 repo 커밋으로 남아 있다.
3. **방법론** — 코드 전에 시뮬로 재미 전제를 실측(게이트 1차), 스펙을 적대 리뷰 3방향으로 검증(must-fix 9건), 판돈 상수를 시뮬로 확정(게이트 2차). 이 과정이 AI 활용 기술 문서의 한 장이 된다.

**플랫폼:** 웹 (데스크톱 우선, 클릭·터치만으로 플레이 가능). GitHub Pages, 링크 클릭 즉시 플레이. 로그인·설치 없음.

**전작이 남긴 제1 계약** (`C-player-needs-a-failure-axis`): 난이도는 "플레이어가 못 하는 것"에서 나온다. 이 게임의 실패 축은 ① **인간은 랜덤을 만들지 못한다**(시뮬 실측: 사람 흉내 정책은 50% 기준선 대비 67~82% 잡힘) ② **욕심**(스트릭을 쌓을수록 몰수 리스크가 커진다). 둘 다 밸런스 값이 아니라 인지 한계와 수학이라, 전작의 사인("값 조정으로 도달 불가능한 쉬움")이 재발할 수 없다.

## 3. 게임 디자인

### 3.1 코어 루프 (1판 ≈ 3~4분, 12라운드 = 관찰 1 + 본게임 11)

```
[관찰 1라운드]  덫 없음. "지금부터 당신을 관찰한다"
   선택·수익·스트릭은 본게임과 동일(안전한 온보딩 — 첫 덫 라운드에 이미 미정산이 있다)
      ↓
[본게임 11라운드]  매 라운드:
   ① AI가 몰래 한쪽 금고에 덫 (로컬 앙상블 즉답 — 대기 0초)
   ② 플레이어: 왼쪽/오른쪽 금고 클릭 (또는 ←/→)
   ③ 즉시 판정 — **덫 위치는 결과와 무관하게 항상 공개된다**
      통과: 미정산 += 100 × (스트릭+1), 그 후 스트릭+1. 덫이 있던 반대편 금고가 불탄다(니어미스)
      잡힘: "예측됨" 스탬프 + 근거 공개(§3.3 귀속 템플릿 — "직전에 잡힌 뒤, 넌 6번 중 5번 반대로 도망쳤다")
            미정산 전액 몰수, 스트릭 0
   ④ [정산] 버튼: 라운드 사이 언제든. 미정산 → 은행 확정, 스트릭 0
      ↓
[읽기 세션 3회]  본게임 3R·6R·9R 후 — LLM이 이력을 읽고 (타이핑 연출)
   심리 프로파일 선언 + 도발 + 전략 교체(비표시 — 디렉터 로그 토글에서만 노출)
   **선언한 읽기는 다음 2라운드 동안 실제 덫 정책이 된다** (§3.4 약속 창)
      ↓
[종료]  11라운드 소진(미정산 자동 정산) → 은행 ≥ 목표액이면 승리, 미달이면 패배
   조기 종료: 은행이 목표액에 이미 도달(승리 확정) 또는 남은 최대 가능 수익으로도 도달 불가(수학적 사망)
   가 되면 남은 라운드를 건너뛰고 바로 연출로 — 죽은 라운드를 만들지 않는다
   양 경로 모두 LLM 심리 분석 리포트(≈400자) + 칭호 → 리스타트 1클릭
[리스타트]  앙상블·이력은 리셋하지 않는다 — "다시 왔군. 네 버릇은 기억하고 있다"
   (2판째가 더 어려워진다: 관찰 라운드 무료 수익 재수집·학습된 착취 재사용 차단 + 재도전 서사)
```

- 판정·정산·근거가 **라운드 안에서 즉시** — 전작 amendment #5의 교훈(정산은 비트 안에, 시차 0).
- 조작은 클릭 2종 + 정산 버튼뿐. 심사자 입력 부담 0.

### 3.2 판돈 수학 — 욕심의 축

| 항목 | 초안값 | 규칙 |
|---|---|---|
| 통과 수익 | 100 × (스트릭+1) | **미정산 += 100×(스트릭+1), 그 후 스트릭 += 1** (수익 열: 100, 200, 300…) |
| 몰수 | 미정산 전액 | 확정 — 절반 완화 없이 4밴드 성립 |
| 정산 | 무료 행동, 스트릭 리셋 | "챙길까 더 갈까"가 매 라운드의 결정 |
| 목표액 T | **1,000 (게이트 2차 확정)** | 900은 역읽기 71%로 과잉, 1,100+는 45% 미달 |

**시뮬 게이트 2차 — 성립 조건 4밴드 (사전 선언. 실게임 규칙 전체(약속 창·반심기·프리셋 포함)로 측정):**
1. 읽히는 무전략 플레이(약속 창 무시): 승률 **<15%**
2. 역읽기 플레이(약속 창 활용 + 상식적 정산): 승률 **45~70%**
3. 랜덤 + 무전략 정산: 승률 **10~30%** (운으로도 가끔 이겨야 리스타트 동기가 산다)
4. **심기 정책군(sandbag — 초반 일부러 잡히며 패턴 심기 → 후반 반전)의 최고 승률이 밴드 2를 넘지 못할 것** — 지배 전략 차단 확인

> **게이트 2차 결과 (2026-08-08, `tests/heist_gate.test.ts` 1200게임/정책·시드 고정):** T=1000에서 4밴드 전부 성립 — 무전략 9.9% · 역읽기 49.9% · 랜덤 20.2% · 심기 최고 0.0%.
> 경위: 세션 2회 구조에서는 성립하지 않았다. ① 반전(심기 후 뒤집기)의 수익 상한이 ~1,100이라 T≤1100에서 심기 승률 97.7%의 절벽이 생기고 ② T≥1200에서는 역읽기가 42%로 미달 — 해가 없었다. **세션 3회(3R·6R·9R 후)**로 바꾸자 심기가 0%로 죽는다: 한 번 뒤집으면 다음 세션(≤3라운드 뒤)이 갱신된 후보로 반전을 읽고 새 선언을 걸어 처벌한다. 심기가 이기려면 선언을 들어야 하고, 그것은 곧 역읽기(밴드 2)다 — 착취가 의도된 스킬로 수렴한다.
> 1차 리뷰 실측(약속 창 없이는 어떤 T에도 해 없음·심기 100% 지배)은 이 게이트의 존재 이유로 §8에 남긴다.

### 3.3 예측 엔진 — 로컬 앙상블 (시뮬 게이트 1차 통과)

**구성:** 예측기 5종의 성적 가중(지수감쇠) 앙상블. 전부 결정론·로컬·즉답.

| 예측기 | 잡는 패턴 | 프라이어 | 근거 템플릿 (잡힘 시 실제 수치 채워 표시) |
|---|---|---|---|
| freq | 위치 편향 | 약한 균등 | "넌 {n}번 중 {k}번 {door}만 골랐다" |
| ngram1 | 직전 선택 → 다음 | **반복 회피** | "{door} 다음에 넌 {k}/{n}번 {next}로 갔다" |
| ngram2·3 | 짧은 시퀀스 습관 | 없음 | "{seq} 다음은 늘 {next}였지" |
| wsls | 잡힘/통과 직후 반응 | **잡힌 문 회피** | "잡힌 뒤, 넌 {k}/{n}번 반대로 도망쳤다" |

- **잡힘 근거는 전부 로컬 생성이다** (매 라운드 LLM 호출 금지 — 호출 예산 §3.4). 엔진이 덫을 결정한 **최대 기여 예측기**(가중 × 덫 문 확률)를 귀속시키고, 위 템플릿에 그 예측기의 실제 이력 수치를 채운다. **불변식: 표시된 근거 = 실제 덫 결정 요인** (유닛 테스트 대상 — 날조 구조적 차단).
- **반심기 트리거 (엔진 자율, LLM 무관):** 최근 **2개** 비약속 라운드 전패(적중 0)면 예측기 성적을 급감쇠(×0.5)하고 적중이 나올 때까지 CONTRARIAN을 50% 혼합한다. 게이트 2차에서 확정 — 5라운드 룩백은 반전이 끝난 뒤에야 무장돼 무력했고(심기 승률 97.7% 방치), 세션 사이 비약속 라운드가 2개뿐이라 2가 유일하게 작동하는 값이다.
- **리스타트 승계:** 같은 페이지 세션의 재도전은 앙상블 상태·이력을 프라이어로 이어받는다(§3.1).

**시뮬 실측 (2026-08-08, `scripts/mindread_sim.js` — 2000게임×정책, 재실행 시 ±1pt 변동):**

| 상대 정책 (ε=0.25 노이즈) | 2문 적중률 (기준선 50%) |
|---|---|
| 반복 회피형 | **82.4%** |
| 순환형 | 69.7% |
| 승유지·패전환형 | 66.7% |
| 혼합형(사람에 가장 근접) | **74.3%** |
| 2차 추론형(잡힌 문 일부러 반복) | 51.0% — 유일하게 중립화 |
| 순수 랜덤 | 50.0% (과적합 없음 확인) |

**판정:** 사전 선언 기준(패턴 평균 62%+·혼합형 55%+·랜덤 47~53%) 전부 통과 — 패턴 평균 68.8%. 3문은 ~40%로 탈락 → **2문 확정**. 관찰 2→1라운드 축소 변형도 리뷰 라운드에서 실측 통과(패턴 평균 69.5%, 혼합형 첫 덫 라운드 적중 70%). 1차(프라이어 없는 백지 앙상블)는 미달이었고, 인간 편향 프라이어 + 관찰 라운드로 통과 — 경위는 기술 문서에 기재.

**설계 함의:** 2차 추론(AI가 입 밖에 낸 읽기를 역이용)만이 앙상블을 중립화한다 = "내가 AI를 읽었다"가 실측으로 보장된 승리 스킬이다. 다만 적응형 앙상블 상대로는 역이용도 통과율 ~50%가 상한이라(리뷰 실측), 그것만으로는 승리 수학이 성립하지 않는다 — **약속 창이 그 간극을 메운다**(§3.4).

### 3.4 디렉터(LLM) — 권한 경계

**원칙 (전작 승계): LLM에게는 어휘를, 집행은 결정론으로.** LLM은 수치·좌표·확률을 정하지 못한다.

**입력 (읽기 세션마다):** 선택·잡힘·정산 이력, 스트릭 행동(욕심 지표), 앙상블 예측기별 성적, **엔진이 산출한 실존 패턴 후보 목록**(각 예측기의 현재 통계 — 상위 2개).

**세션은 3회다(본게임 3R·6R·9R 후)** — 게이트 2차에서 2회→3회로 확정(§3.2 경위). 첫 세션이 3R 후로 당겨져 심사 리뷰의 "첫 30초" 요구에도 부합한다.

**출력 — 디렉티브 v2:**
```json
{
  "readPatternId": "FREQ|ALTERNATE|SEQUENCE|AFTER_CAUGHT — 엔진이 준 후보 중에서만 선택",
  "read":     "≤60자 — 선택한 패턴의 패러프레이즈 (화면 표시). 자유 주장 금지",
  "taunt":    "≤40자 — 도발",
  "strategy": "BALANCED|PRIOR_HEAVY|RECENT_ONLY|PATTERN_HEAVY|CONTRARIAN|BAIT",
  "baitDoor": "L|R|NONE — BAIT일 때만: taunt가 그 문을 직접 언급",
  "intent":   "≤80자 — 설계 의도 (리포트·디렉터 로그용)"
}
```

**약속 창 (핵심 신규 — "말한 읽기는 지킨다"):** 세션이 선언한 `readPatternId`는 **다음 2라운드 동안 실제 덫 정책이 된다** — 그 2라운드의 덫은 해당 예측기 단독의 argmax다. 선언을 흘려들으면 자기 패턴 그대로 잡히고, **선언을 역이용하면(그 모델이 기대하는 반대로 가면) 확정적으로 통과한다.** 이것이 역읽기 스킬 채널(§3.2 밴드 2)이자, "AI의 말은 계약"이라는 정직성 증명이다. 창 종료 후는 `strategy` 프리셋의 적응 앙상블로 복귀.

**전략 프리셋 (수치는 엔진 소유 — 초안값, 게이트 2차에서 확정):**

| 프리셋 | 집행 |
|---|---|
| BALANCED | 성적 가중 기본 앙상블 |
| PRIOR_HEAVY | ngram1·wsls 가중 ×2 |
| RECENT_ONLY | 성적 감쇠 0.9 → 0.7 (최근 편중) |
| PATTERN_HEAVY | ngram2·3 가중 ×2 |
| CONTRARIAN | 앙상블 argmax의 **반대** 문에 덫 (역이용 대응) |
| BAIT | 창 종료 직후 1라운드, `baitDoor` 반대편에 0.7 가중 — 도발로 지목된 문을 피하는 편향을 노림. 허세를 맞받으면(지목된 문 선택) 유리 |

- 프리셋 지속: 다음 읽기 세션까지. **화면 비표시** — 디렉터 로그 토글에서만 노출(CONTRARIAN 텔레그래프 방지).
- 검증(전작 validator 정책 승계): **길이 초과 = 절단**(폴백 아님 — 전작이 코드에 기록한 결정), `baitDoor` 조건 위반 = `NONE` 정규화, `readPatternId`가 후보 밖 = 그 세션만 폴백. 폴백은 enum·구조 위반만.
- **호출 예산: 런당 5회** (읽기 세션 3 + 최종 리포트 1 + 타이틀 워밍업 1). 세션 상한 20·일일 캡·CORS 재사용.
- **폴백 (조립형 — 정적 단일 템플릿 금지):** 엔진의 최상위 패턴 후보로 read를 템플릿 조립 + 도발 뱅크 + `BALANCED`. 최종 리포트 폴백도 통계(잡힌 패턴·욕심 지표) 기반 조립형. 폴백에서도 "실제 이력 지목"은 유지된다.

**최종 리포트:** 전체 런 요약 → 심리 프로파일 400자 + 칭호(예: "청개구리", "간 큰 도둑"). 재도전 판이면 판 수·변화도 언급.

### 3.5 비주얼·오디오

- 전작 아이덴티티 유지: 다크(#0a0a0f) + 무채색 지오메트리 + **레드 = AI의 것**. 외부 에셋 0.
- 화면: 상단 AI의 눈(커서 추적) + 대사줄, 중앙 금고 2개, 하단 은행/미정산/스트릭/라운드/[정산].
- **매 라운드 덫 공개 연출**: 통과 = 반대편 금고에 덫 격발(니어미스 — "정말 예측하고 있었다"의 증명), 잡힘 = "예측됨" 스탬프 + 근거 한 줄. 잡힘 스탬프·근거는 **영상에서 읽히는 크기**(§6 완료 기준).
- 주스(전작 재사용): 잡힘 = 화면 흔들림 + 레드 플래시, 통과 = 코인 파티클 + 카운트업, 정산 = 금고 소리. zzfx 4종.
- '디렉터 로그' 토글(전작 재사용): 디렉티브 JSON + 프리셋 상태.

## 7. 리스크·전제

- **체감 난이도:** 적중률 67~82%는 "소름"과 "좌절" 사이 — 덫 상시 공개·근거 표시·약속 창이 "배울 수 있는 패배"를 만드는 장치다. 실플레이에서 좌절 판정 시 규칙 레버: 확신도(= 앙상블 혼합의 max) 0.55 미만이면 그 라운드 덫 없음(자동 숨 고르기). *(초안의 "3연속 잡힘 시 관찰 삽입" 레버는 폐기 — 리뷰 실측에서 심기 착취를 오히려 돕는다(승률 37.8%로 상승).)*
- **프록시 재배포 권한:** Edge Function 갱신은 Supabase CLI 인증 필요 — 세션에서 가능하면 즉시, 불가하면 **승제 액션 아이템(8/9 오전)**. CORS가 Pages 도메인 단일 허용이라 LLM 정상 경로 검증은 Pages 배포 후에만 가능 — 8/9 오전 배포 게이트가 그래서 있다.
- **LLM read 품질·날조:** 구조적으로 차단 — read는 엔진이 준 실존 후보의 선택+패러프레이즈만(§3.4), 잡힘 근거는 아예 로컬 귀속.
- **유료 API:** 런당 4회 × haiku. 캡 재사용.
- **재직자 보증·약관:** 승제 액션 아이템(제출 전).
- **일정:** 신규 코드(예측기 이식+신규 규칙·2문 씬·판돈·근거 생성기·프롬프트)가 이틀에 드는 것이 전제 — 판돈 시뮬은 이식이 아니라 신규 작성임을 견적에 반영했다. P1이 8/9 오전을 넘기면 컷라인 즉시 가동.
