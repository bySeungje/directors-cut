위협은 총 체력이 아니라 **동시 접촉 개체 수**가 만든다는 것을 확정한 실측. chaser 60기=체력 1 손실 / 80기=26 / 100기=36, elite chaser 40기(총 체력 240)=2. 이동 여부가 가르는 폭: chaser 80기에서 정지 26 대 이동 1(26배).

예산 곡선 `8 + n×4 + max(0,n−4)²×6` = 12/16/20/24/34/56/90의 근거이고, 전멸 시간 3.6~29초라는 관측이 [[C-duration-normalized-metrics]]의 전제다.
