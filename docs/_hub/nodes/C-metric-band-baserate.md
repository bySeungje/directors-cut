영역 체류를 재는 지표는 **그 영역이 아레나의 몇 %인지 먼저 계산**한다. 기저율 위에 유의미한 마진이 없으면 습관이 아니라 기하를 재는 것이다.

`WALL_MARGIN=80`, 아레나 960×640 → 벽 밴드 = `1 − 800×480/614400` = **0.375**. 무작위로 움직여도 0.375가 나오는데 임계를 0.50으로 잡았었다.

실측: 도망 0.88~0.94 · 키팅 0.62 · 의식적 중앙 유지 0.50~0.63 · **0.00은 정지할 때뿐.**

어기면: 벽을 떠나는 유일한 방법이 정지가 되는데, 정지는 예산 곡선이 죽이려던 행동이다. 플레이어에게 "잘하려면 죽어라"를 요구하게 된다.
