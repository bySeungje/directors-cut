"이 값을 플레이어가 **어떤 행동으로** 움직이는가"에 답하지 못하면 플레이어 지표가 아니다. 그리고 **깨려는 시도가 지표를 반대로 움직이는지** 반드시 확인한다.

`clusterRatio`는 적들의 **자기 중심점 대비 평균 거리**다. 스폰 패턴과 구성이 지배한다 — `RING`은 320px 원이라 높고, `N`/`BEHIND`는 한 변이라 낮고, `shooter`는 260px를 유지하니 올린다. **전부 디렉터의 선택이다.**

실측: 18개 (구성×전략) 조합 중 **16개에서 임계 0.25 아래**. 가만히 서 있어도 아래다(추격형이 한 점에 수렴하는 게 `moveToObject`의 정의). 적을 흩으려 2초마다 방향을 뒤집으면 **오히려 내려간다**(0.11→0.05).

어기면: 플레이어가 절대 못 깨는 예측이 만들어지고, 하필 선택 규칙상 가장 자주 뽑힌다.
