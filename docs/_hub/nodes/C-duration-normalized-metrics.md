웨이브 간 비교에 쓸 지표는 **롤링 창**(마지막 N초)으로 재거나 **비율**로 정규화한다. 카운트를 비율과 같은 표에 놓지 않는다.

`finish()`의 모든 비율은 총 시간으로 나눈다. 같은 궤적인데 15초 웨이브 `maxQuad 0.89`/`hotspot 0.53`, 30초면 `0.45`/`0.26`. 그리고 예산 곡선(12/16/20/24/34/56/90)상 **다음 웨이브는 항상 더 길다.** 실측 전멸 시간은 3.6~29초로 8배 차이.

`dashCount`는 비율이 아니라 **무한정 카운트**라 더 나쁘다 — 기본 쿨다운 2초 기준 45초 웨이브 초과율 1.75, 70초 3.38, 대시 쿨다운 3회 강화 시 7.50. 다른 지표(상한 1.0~1.86)와 비교 자체가 안 된다.

어기면: "행동을 바꾸면 판정이 뒤집힌다"가 저절로 깨진다. 판정이 플레이어와 무관해진다.
